## [1.0.0] — 2026-10-23

### Features
* **core:** pulse state machine with exhaustive transition table and property tests
* **core:** Redis Streams bus with consumer groups, `XAUTOCLAIM` reclaim and DLQ
* **core:** cost-weighted atomic Lua token bucket with fail-open local fallback
* **core:** HMAC request signing with 300s replay window and nonce store
* **core:** Argon2id secret keys, SHA-256 scoped public keys, rotation with grace
* **core:** pluggable adapters for billing, LLM and TTS with zero-cost defaults
* **api:** FastAPI gateway with six pure-ASGI middleware and eight routers
* **api:** headless Stripe billing; 429 carries `upgrade_url` for instant conversion
* **api:** `GET /source` AGPL section 13 disclosure endpoint
* **api:** commercial buy-out checkout, quote, offline key verification and agreement
* **worker:** orchestrator, budgeted agent, voice coalescer, SSRF-guarded webhook sender
* **scheduler:** leader-elected ticks with orphan lease reaping
* **sdk-android:** two-line integration, adaptive polling, battery governor, on-device TTS
* **sdk-js / sdk-python:** Apache-2.0 clients with HMAC signing

### Security
* nonces rejected outside a 300s window
* SSRF allowlist on webhook egress
* secrets never committed; OIDC used for all publishing
* SLSA level 2 provenance and keyless cosign signatures on every image

### Documentation
* architecture, threat model, runbook, AGPL compliance, telemetry, versioning policy
* six ADRs covering every irreversible decision
* asset dossier with pre-written due-diligence answers
