# ProPulse licensing notes

- Server and core engine: **AGPL-3.0-or-later**.
- Android, JavaScript, and Python SDKs: **Apache-2.0**.
- A future commercial `propulse-pro` package, if distributed, has a separate commercial license.

The AGPL license text is in `LICENSES/AGPL-3.0-or-later.txt`; the SDK license text is in `LICENSES/Apache-2.0.txt`. See `TRADEMARK.md` for the separate treatment of project names and marks.

The `GET /source` endpoint is intended to help deployments provide source and build information. It does not replace the license obligations that apply to a specific distribution or deployment. Obtain qualified legal advice for questions about a particular use or commercial arrangement.
